# 🍽️ Meal-Metrics 360 🚀

MealMetrics 360 is a **restaurant analytics platform** that provides **real-time insights📊, predictive analytics📈, and operational optimization⚙️** for restaurant managers. It leverages **machine learning** to improve decision-making and **maximize profitability💰**.

## 🌟 Features
- 🔍 **Real-Time Analytics** – Monitor customer behavior, sales trends, and service speed.
- 🔮 **Predictive Insights** – Forecast menu performance and resource needs using historical data.
- 🔄 **Scalability** – Supports single restaurants and large chains with adaptable configurations.
- 🔗 **Seamless Management** – Integrates with POS systems for unified operations.
- 🔐 **Robust Security** – Protects data with encryption and role-based access control.
- ⚡ **Streamlined Data Workflow** – Ensures efficient data flow from input to analytics and visualization.

## 🛠 Tech Stack
### 🎨 Frontend:
- ⚛️ **React.js** – Responsive UI with interactive visualizations.
- 📊 **Chart.js** – Data visualization.
- 🎨 **HTML, CSS** – Styling and layout.

### 🖥️ Backend:
- 🐍 **Python (Flask)** – API development and request handling.
- 🔗 **RESTful APIs** – Smooth communication between frontend and backend.

### 🗄️ Database:
- 🛢 **MySQL** – Data storage and management.
- ☁️ **AWS** – Cloud deployment and hosting.

### 🔧 Tools & Libraries:
- 🛠 **Postman** – API testing.
- 🔀 **Git & GitHub** – Version control.

## ⚙️ Installation & Setup
1. **Clone the Repository:**
   ```sh
   git clone https://github.com/Shiva-Prasad-M/MealMetrics360.git
   cd MealMetrics360
   ```
2. **Backend Setup:**
   ```sh
   cd backend
   python -m venv venv
   source venv/bin/activate  # On Windows use 'venv\Scripts\activate'
   pip install -r requirements.txt
   python app.py
   ```
3. **Frontend Setup:**
   ```sh
   cd frontend
   npm install
   npm start
   ```

## 🌐 API Endpoints
| ⚡ Method | 🔗 Endpoint | 📝 Description |
|----------|------------|---------------|
| `POST` | `/api/auth/login` | User login 🔑 |
| `POST` | `/api/auth/register` | User registration 📝 |
| `GET` | `/api/meals` | Get meal list 🍽️ |
| `POST` | `/api/meals/add` | Add a new meal 🍔 |
| `GET` | `/api/reports/sales` | Sales analytics report 📊 |
